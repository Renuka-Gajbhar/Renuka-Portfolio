
# Renuka's Developer Portfolio

A personal developer portfolio website showcasing my introduction, technical skills, projects, and professional profiles.

## Project Overview

This portfolio website represents my academic background, programming skills, projects, and career interests. It is designed to provide a professional online presence and help visitors connect with me.

## Technologies Used

- HTML5 – For website structure and content.
- CSS3 – For styling, layouts, colors, and responsive design.

## Project Features

- Home section with personal introduction.
- About Me section.
- Technical Skills section.
- Featured Projects section.
- Contact section.
- LinkedIn profile link.
- GitHub account link.
- Download Resume option.
- Responsive website layout.

## Week 2: CSS – Styling Your Website

In Week 2, I enhanced my existing HTML portfolio using an external CSS stylesheet. I focused on creating a visually appealing, professional, and responsive user interface.

### CSS Concepts Used

1. **CSS Selectors**
   - Element selectors
   - Class selectors
   - ID selectors
   - Pseudo-classes such as `:hover`

2. **CSS Properties**
   - Colors and backgrounds
   - Font styles and sizes
   - Borders and border-radius
   - Margins and padding
   - Box shadows and transitions

3. **CSS Box Model**

   Used content, padding, border, and margin to control spacing and element sizes.

4. **Flexbox**

   Used `display: flex` to align navigation links, buttons, and other elements.

5. **CSS Grid**

   Used `display: grid` to arrange the homepage content and project cards.

6. **CSS Positioning**

   Used relative and absolute positioning for visual elements and layout adjustments.

7. **Hover Effects and Transitions**

   Added interactive hover effects to buttons, navigation links, and project cards.

8. **Responsive Design**

   Used CSS media queries to adjust the website layout for mobile and tablet screens.

### Design Decisions

- Selected a modern purple color theme with cyan and pink accents.
- Created a glass-style hero section.
- Placed personal introduction on the left and profile image on the right.
- Added professional LinkedIn, GitHub, and Resume buttons.
- Used cards to display projects and skills.
- Designed a responsive layout for different screen sizes.

## Setup Instructions

Follow these steps to run the portfolio website:

1. Clone or download this GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and the images folder are present.
4. Open `index.html` in a web browser.
5. Explore the Home, About, Skills, Projects, and Contact sections.
