## Week 2: CSS – Styling Your Website

In Week 2, I enhanced my existing HTML portfolio using an external CSS stylesheet. I focused on creating a visually appealing, professional, and responsive user interface.

### CSS Concepts Used

1. **CSS Selectors**
   - Element selectors
   - Class selectors
   - ID selectors
   - Pseudo-classes such as `:hover`

2. **CSS Properties**
   - Colors and backgrounds
   - Font styles and sizes
   - Borders and border-radius
   - Margins and padding
   - Box shadows and transitions

3. **CSS Box Model**

   Used content, padding, border, and margin to control spacing and element sizes.

4. **Flexbox**

   Used `display: flex` to align navigation links, buttons, and other elements.

5. **CSS Grid**

   Used `display: grid` to arrange the homepage content and project cards.

6. **CSS Positioning**

   Used relative and absolute positioning for visual elements and layout adjustments.

7. **Hover Effects and Transitions**

   Added interactive hover effects to buttons, navigation links, and project cards.

8. **Responsive Design**

   Used CSS media queries to adjust the website layout for mobile and tablet screens.

### Design Decisions

- Selected a modern purple color theme with cyan and pink accents.
- Created a glass-style hero section.
- Placed personal introduction on the left and profile image on the right.
- Added professional LinkedIn, GitHub, and Resume buttons.
- Used cards to display projects and skills.
- Designed a responsive layout for different screen sizes.

# Interactive Portfolio Website

The **Interactive Portfolio Website** is a personal portfolio developed to showcase my profile, technical skills, projects, and professional achievements.

This project is part of **Week 3: JavaScript – Making Websites Interactive**. The main objective is to make my existing portfolio more interactive and user-friendly using JavaScript.

## JavaScript Implementation

JavaScript is used to make the portfolio interactive.

The `script.js` file contains reusable functions for:

1. Form Validation – Checks user input and displays appropriate error messages.
2. Dark Mode – Allows users to switch between light and dark themes.
3. DOM Manipulation – Updates website content dynamically.


## Form Validation Logic

The contact form validates the following fields:

- Name must not be empty.
- Email must be in a valid format.
- Message must contain at least 10 characters.
- Error messages are displayed when the input is invalid.
- A success message is displayed when all validations pass.

## Setup Instructions

Follow these steps to run the project:

1. Clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Check that the profile image is available inside the `images` folder.
5. Open `index.html` in your browser.
6. Test the interactive features.
